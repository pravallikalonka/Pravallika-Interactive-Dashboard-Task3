# House Price KPI Analysis & Interactive Dashboard Project

## Introduction

This project was completed as part of the ApexPlanet Data Analytics Internship Program.

The objective of Task 3 was to perform deep-dive business analysis on housing market data by developing KPI-driven insights, advanced segmentation, and dashboard planning strategies for strategic business intelligence.

---

## Project Goals

* Develop key performance indicators (KPIs)
* Perform advanced market segmentation
* Analyze pricing patterns across categories
* Identify business trends
* Build strategic dashboard plans
* Generate actionable business insights

---

## Technologies Used

* Python
* Pandas
* Matplotlib
* Dashboard Planning Tools (Power BI / Tableau / Excel)

---

## Project Structure

* `kpi_analysis.py` → KPI calculations and performance metrics
* `deep_dive_analysis.py` → Segmentation and advanced analysis
* `dashboard_report.md` → Dashboard planning and KPI strategy
* `cleaned_housing_data.csv` → Cleaned housing dataset
